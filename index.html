Drei Schritte mit GitHub Pages

  1. 01 / Dateien

    Ins Repository legen

    Die Startseite heißt index.html. CSS, JavaScript und Bilder können direkt daneben liegen.

  2. 02 / Veröffentlichen

    GitHub Pages aktivieren

    Unter Settings → Pages den Branch und den Ordner mit der Website als Quelle auswählen.

  3. 03 / Aktualisieren

    Ändern und committen

    Neue Änderungen in der gewählten Quelle werden automatisch veröffentlicht. Die URL bleibt gleich.
